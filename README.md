# 🚕 Análise de Logs e Consultas SQL — Chicago Taxi

## 📌 Sobre o projeto

Este projeto foi desenvolvido como parte da formação em Garantia de Qualidade da TripleTen.

O objetivo foi trabalhar com análise de logs no console e consultas em banco de dados, utilizando dados de um aplicativo de corridas de táxi.

## 🎯 Atividades realizadas

- Análise de logs em servidor remoto
- Identificação de solicitações por endereço IP
- Filtragem de registros por data e códigos de erro
- Organização de arquivos e diretórios no console
- Separação de logs com erros 400 e 500
- Consultas em banco de dados PostgreSQL
- Utilização de funções de agregação
- Agrupamento e filtragem de dados
- Análise de dados relacionados a corridas de táxi e condições climáticas

## 🖥️ Análise de logs

Foram realizadas atividades como:

- Busca de solicitações por endereço IP
- Identificação de registros em diferentes datas
- Seleção de logs relacionados a erros 400 e 500
- Criação de diretórios e arquivos para organização dos registros
- Separação dos logs de acordo com o código de erro

## 🗄️ Consultas SQL

Foram realizadas consultas para:

- Contar o número total de táxis disponíveis
- Identificar empresas com menos de 100 veículos
- Classificar as condições climáticas como `Good` ou `Bad`
- Analisar o número de corridas por empresa de táxi
- Utilizar `CASE`, `HAVING`, `GROUP BY` e funções de agregação
- Relacionar dados de diferentes tabelas
